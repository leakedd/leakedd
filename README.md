## 👋 About me

I build, debug, and improve developer tools and AI agent systems. I like following a bug all the way from the symptom to the real execution path, then locking the fix down with regression tests.

## 🚀 Selected work

### Hermes Agent

- Found and reproduced a Desktop/TUI bug where <code>prefill_messages_file</code> was silently ignored.
- Traced the execution path to <code>tui_gateway.server._make_agent</code> and submitted the tested [PR #105945](https://github.com/NousResearch/hermes-agent/pull/105945).
- The upstream [PR #122251](https://github.com/NousResearch/hermes-agent/pull/122251) superseded that work, was merged, and explicitly credits me for finding the call site.
